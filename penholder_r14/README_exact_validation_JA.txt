保存メッシュの厳密交差検査

この検査はSTLに実際に保存された三角形を対象にする。有限浮動小数点座標は2の整数乗を分母に持つ有理数なので、全座標を同じ2の整数乗で拡大し、任意精度整数へ正確に変換できる。GMPの整数演算で平面の向きを判定し、非共面では三角形と平面の交線区間を有理数で比較する。共面では2次元へ射影して頂点包含と辺交点を判定する。幾何学的な許容誤差は使わない。

通常の隣接面は除外する。ただし、交差全体が実際の共有頂点または共有辺に含まれる場合に限る。頂点を1個共有する三角形が他の場所でも交差する場合は異常として残す。共面の面積重複、通常の共有点以外での点接触と線接触、非共面の実交差、退化三角形を分けて報告する。

必要な環境
Python3.12以降、NumPy、trimesh、rtree。C++17のg++、GMP開発用ヘッダーとライブラリ、OpenMPが必要。外部通信や自動パッケージ導入は行わない。補助の保存メッシュ位相検証・包含検証にはSciPy、PyMeshLab、VTK、manifold3dも用いる。実行に使用したバージョンはrequirements_independent_validation.txtに記録した。

ビルド
python build_exact_engines.py
未ビルドまたはソース更新後はrunnerも同じビルドを実行する。コマンドはg++ -std=c++17 -O2、全体走査には-fopenmpを追加し、-lgmpxx -lgmpをリンクする。

述語の確認
python test_exact_triangle_pairs.py
解析的15ケースを三角形の頂点順序36通りで確認し、計540件が一致した。共有頂点以外で交差する例、共面の面積重複、2^-80の微小な隙間と交差、退化三角形を含む。
python test_exact_mesh_bvh.py
固定乱数種の106三角形について総当たり5,565対とBVHを比較し、異常1,365対が1スレッドと3スレッドの両方で完全一致した。漏れと追加はいずれも0だった。

全メッシュ走査
python run_exact_mesh_bvh.py model.stl --out exact_report.json --threads 3
保存座標が完全に同じ頂点だけを同一視する。すべての三角形から軸に平行な外接箱を作り、階層的な境界箱（BVH）で重なる箱の対を漏れなく列挙する。MeshLabの選択結果による絞込みは使わない。三角形の退化は対の有無にかかわらず別に全数確認する。検査前後の入力SHA256を比較し、結果JSONに記録する。
JSONと同名のNPZに異常な面ID対、分類コード、退化面IDを保存する。面IDは入力STLの0始まりの面順であり、再生成された別ハッシュのSTLへ転用しない。中間の整数化用入力は既定で削除し、--keep-inputで残せる。

選択面内だけの迅速な検査
python run_exact_triangle_pairs.py selection.npz --out selected_exact.json
NPZはface_idsとtriangles_saved_mmを持つ。過去のENU検査用のtriangles_enu_mmにも対応するが、保存print座標を厳密に検査するときはtriangles_saved_mmを使う。ENUへの逆変換値を使うと、元STLとは異なる浮動小数点座標を検査することになる。選択面だけの結果は全体の無交差証明ではない。

位相と含まれる表面
validate_saved_meshes.pyは辺の面数・向き、頂点リンク、連結成分、面積・符号付き体積、PyMeshLab選択を保存する。prepare_component_inventory.pyは成分一覧と主成分抽出の三角形一致を記録する。verify_component_nesting.pyはすべての副成分の全境界頂点を主部への包含で確認し、全主副三角形の候補対を厳密述語で確認する。包含に不一致がある成分を体積閾値だけで除去してはいけない。verify_secondary_core_separation.pyは向きを反転した負向き閉面の内部も含め、最終14流路coreからの分離を確認する。

限界
厳密性は保存座標に対する数学的な交差判定を意味し、設計面や実物寸法の誤差をなくすものではない。無交差でも辺・頂点の多様体性、壁厚、流路連通、開口、支持体適性、実SLA造形、実通液は別に確認する。支持体を含まない検査から印刷合格を主張しない。
